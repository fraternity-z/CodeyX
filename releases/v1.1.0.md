# CodeyX v1.1.0 · 内置工具与远程连接改进

本次更新新增 CodeGraph 自动索引，将文件检索与代码关系分析集中到「内置工具」，完善链接 Skill 管理，并修复本地路由对远程连接的干扰。

## 本次亮点

### 统一管理内置工具

- 在「内置工具」中管理 FastCtx 与 CodeGraph，分别用于文件检索和符号、调用链及模块依赖分析。
- 启用 CodeGraph 后，项目聊天会在后台建立索引并持续同步代码变化；首次索引期间可继续聊天，关闭后保留已有索引。
- 展示最近项目的索引状态，并保留用户已有的 CodeGraph 配置，避免重复接入。

### 支持目录链接中的 Skill

- 用户和项目范围可识别目录链接中的 Skill，按真实路径匹配启停规则。
- 链接内 Skill 支持查看、导出和启停，并标明来源；编辑和删除仍需在源目录处理。

## 优化与修复

- 修复本地路由配置影响 SSH、WSL 和云端连接的问题，远程连接保留原生供应商与传输设置。
- 改进设置重新打开时的草稿合并，避免迟到的配置刷新覆盖刚修改的内容。
- 改进请求日志的筛选与分页，重新打开或刷新后同步重置页码和游标，避免旧查询覆盖新结果。
- 加强线路管理的重复提交保护，隐藏页面时暂停被动刷新，保留未保存草稿。
- 统一界面、通知、Windows 安装包与程序元数据中的 CodeyX 名称。
- 完善设置保存、版本冲突、内置工具、请求日志和更新公告的浏览器回归验证。
- 整理插件开发与管理文档，以插件 SDK 为统一协议入口。

## 升级须知

- 主要面向 **Windows x64** 开发、测试与发布；升级前请结束正在进行的 Codex 任务。
- FastCtx 开关移至「内置工具」，保存后需下次启动生效。
- CodeGraph 为可选功能，首次启用需下载官方运行包；下一轮项目聊天开始自动接入。
