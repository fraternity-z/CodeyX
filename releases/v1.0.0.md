# CodeyX v1.0.0 · 首次发布

CodeyX 首个正式版本，从 **1.0.0** 开始独立维护。面向 Windows，将 Codex 的模型线路、账号、会话和扩展集中在一个控制台中管理。

## 本次亮点

### 多线路与 Gemini 接入

- 支持 OpenAI Responses、Chat Completions、Anthropic Messages 和 Gemini 线路，在任务中切换模型与思考强度。
- 按线路能力提供上下文压缩，支持跨线路继续对话。
- 查看请求耗时、输出速度、Token 用量与错误分布。

### 账号、会话与协作

- 管理多个 ChatGPT 账号，查看额度并选择默认账号。
- 导入导出会话，删除指定轮次并从备份恢复。
- 一键优化提示词，根据本对话改动生成中文 Git 提交说明。
- 为子代理分配模型与思考深度，并通过飞书、企业微信、Telegram、ntfy 或微信 ClawBot 接收任务通知。

### 扩展与手机远程

- 统一管理 MCP、Skill 和可信原生插件，通过插件扩展模型线路与账号接入。
- 可选启用 FastCtx 文件工具和 Codey Computer Use 桌面操作工具。
- 通过局域网或 HTTPS 隧道在手机上继续电脑会话，支持拍照和发送照片。

### GitHub Releases 更新与完整公告

- 从本项目 GitHub Releases 检查稳定版或实验版更新，并在客户端阅读完整公告。
- 公告支持 Markdown、表格、代码和图片，适配明暗主题与窄屏。
- 下载与安装分别确认，安装前校验版本和文件摘要。

## 使用须知

- 当前主要面向 **Windows x64** 开发、测试与发布，其他平台不在维护范围内。
- 安装后打开 CodeyX 启动 Codex；启动可能重启客户端，请先结束正在进行的任务。
- 模型能力、上下文上限及跨线路兼容性取决于服务商和 Codex 版本。
- 仅安装可信来源的原生插件；插件拥有与 CodeyX 相同的系统权限。第三方密钥及部分通知凭据以明文保存在本地私有配置和备份中，请妥善保管。
- 手机远程需手动开启并配对，电脑须保持运行；局域网仅用于可信网络，临时隧道经过 Cloudflare 且地址会变化。
