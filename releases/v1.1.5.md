# CodeyX v1.1.5 · 配置备份与 Ponytail 管理

本次更新新增配置备份与 WebDAV 云备份、Ponytail 插件管理，支持重新选择 Codex 安装目录，并修复会话导入后的清理与凭据输入问题。

## 本次亮点

### 配置备份与恢复

支持将配置导出为 JSON，或通过 WebDAV 上传和下载备份；恢复前预览备份内容，校验通过后保留回退快照，并保留本机账号、插件线路、代理池及本机路径。

### Ponytail 插件管理

支持按需安装、启停 Ponytail，并独立保存新聊天的默认模式；停用时保留插件文件，已有来源冲突时不接管。

### 重新选择 Codex 安装目录

支持从系统设置重新选择 Codex 安装目录，识别及保存时均校验应用身份，选择无效目录时保留原配置。

## 优化与修复

- 修复导入会话的标识识别，确保导入及重复导入的会话可正常列出和永久清理。
- 修复官方账号凭据输入包含中文或其他多字节字符时可能触发的异常，避免诊断信息暴露凭据。
- 完善配置备份恢复的字段校验、配置冲突检测与本机受管理线路保护。
- 统一更新策略为正式版更新或关闭自动检查，不再推荐预发布版本。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- 配置备份可能包含明文 API Key 和其他凭据，请妥善保存，仅上传至可信的 WebDAV 服务；备份不包含会话、扩展文件或系统密钥库内容。
- Ponytail 首次安装需要 Node.js 和 Git；安装后请重启 Codex，在 `/hooks` 中检查并信任钩子，再开始新聊天。
- macOS arm64 提供未签名应用包。
