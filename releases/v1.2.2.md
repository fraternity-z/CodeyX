# CodeyX v1.2.2 · 客户端修复与代理体验改进

本次更新汇总自 v1.2.0 以来的变化，新增 MCP 共享、Windows 独立客户端注入修复和更新下载源选择，简化线路代理配置，并改进新版 Codex 兼容性与连接恢复。

## 本次亮点

### Windows 独立客户端修复

支持在确认停止所选客户端后修复兼容的主进程注入入口，修复前备份并校验文件，提供回滚能力。

### 线路代理与更新下载源

线路代理简化为开关和代理池节点选择；系统设置可选择 GitHub 官方源或 GH-Proxy 下载安装包，代理下载失败时回退 GitHub，并继续使用 GitHub 提供的文件大小和 SHA-256 校验。

### MCP 共享与启动体验

支持按需共享内置 FastCtx、CodeGraph 和兼容的本地 MCP 服务，并发请求按需分配实例，可释放空闲实例而不打断正在执行的请求；新增适配明暗主题的启动动画。

## 优化与修复

- 修复侧边栏增强按钮在新版 Codex 原生操作栏中的插入位置。
- 改进网络切换后的连接恢复，以及 Windows 重启 Codex 时的设置保存。
- 优化流式响应解析，减少分块边界的重复扫描，并加强错误日志脱敏。
- 预加载配置面板，减少 MCP 状态扫描和隐藏页面的会话统计调度。
- 改进会话文件名标识识别与清理范围校验。
- 更新设置入口图标，统一品牌标识。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- 旧代理链路和出口策略数据保留兼容；已绑定旧选择的线路需改选代理池节点或关闭代理开关。
- Windows 注入修复仅适用于可验证的兼容独立客户端，不修改 Store 安装；修复会使客户端 DLL 原厂签名失效，客户端更新可能覆盖补丁。
- MCP 共享仅适用于无状态且允许多实例运行的工具服务；依赖客户端回调、资源订阅或持续任务的服务应保持直连，内置工具共享开关需重启 Codex 生效。
- GH-Proxy 为第三方下载服务，版本信息与完整性校验仍以 GitHub 为准。
- macOS arm64 提供未签名应用包。
