# CodeyX v1.1.2 · 新版 Codex 兼容与连接稳定性

本次更新改进新版 Codex 的启动与会话操作兼容性，完善页面连接恢复和大会话处理，并更新应用图标。

## 本次亮点

### 适配新版 Codex

改进本地路由接管与启动校验，减少对 Codex 内部源码结构的依赖；适配新版客户端的本地会话接口，改善消息删除、模型路由与任务完成状态读取的兼容性。

### 更新应用图标

采用新的应用图标，同步更新 Windows 与 macOS 图标资源。

## 优化与修复

- 改进页面连接的超时与重连处理；页面刷新或上下文重建后清理旧请求和回调，避免过期回执干扰当前连接。
- 会话轮次删除采用分块处理，限制大文件读取与恢复记录的资源占用，并保留失败后的恢复能力。
- 完善流式响应的缓冲上限检查，优化用量统计查询，减少重复扫描。
- 统一远程控制与内置工具的异步状态管理，忽略过期响应，并保留后台操作期间的重复提交保护。

## 升级须知

- 主要面向 **Windows x64** 开发、测试与发布；升级前请结束正在进行的 Codex 任务。
- 下载与安装仍分别确认，安装前会保存设置并退出当前 CodeyX 实例。
