# CodeyX v1.2.4 · 原生工具与会话稳定性改进

本次更新汇总自 v1.2.2 以来的变化，带来 FastCtx 原生工具和额度消耗提示，并改进会话统计、连接恢复与保护状态展示。

## 本次亮点

### FastCtx 原生工具

FastCtx 改用原生工具提供文件读取、搜索、发现和替换，闲置后自动释放进程，再次调用时按需启动；升级时清理旧受管 MCP 登记，保留用户自定义服务。

### 会话统计与状态同步

修复完成事件重复累计用量和轮次的问题，改进统计面板刷新，并同步同一会话在不同列表中的运行与完成状态。

### 额度消耗提示

侧边栏额度摘要增加消耗节奏和重置时间提示，便于了解当前账号的使用情况。

## 优化与修复

- 加快页面桥接断开后的恢复，连续失败时保留退避。
- 改进 Trace 与 Crashpad 保护状态展示，增加运行期间的检查。
- 优化用量查询调度和会话日志读取，减少重复查询。
- 统一备份、会话、扩展与代理页面的视觉反馈，模型控件统一为列表选择。
- 本地会话历史缺失时支持客户端补发完整输入，改善会话续接；身份变化或缺失推理时仍拒绝恢复。
- 启动代理改为手动地址配置，完善账号文件保护和代理凭据脱敏。
- 修复前端构建依赖中的已知安全漏洞。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- 内置 FastCtx 原生工具仅在兼容客户端的本地完全访问会话中启用；使用自定义 FastCtx 时停用内置工具。
- 代理池和实验性流量接管已移除，旧配置保留但不再参与请求路由；需要启动代理时请手动填写地址，启动代理不保证所有流量经过代理。
- macOS arm64 提供未签名应用包。
