# CodeyX v1.1.4 · 网络代理与子代理配置

本次更新新增网络代理池、自定义子代理与本机会话永久清理，改进新版 Codex 兼容性并减少后台资源占用。

## 本次亮点

### 网络代理池与有序链路

为 Codex 启动和模型线路选择固定代理或按规则分配出口，支持有序代理链路、连通性测试与出口检测；代理池凭据使用系统密钥库保存。

### 自定义子代理

支持添加自定义角色，分别配置读写能力、模型与思考深度，并调整并发数量；新增角色和并发数量修改需重启后生效。

### 本机会话永久清理

支持永久清理本机会话、归档及关联记录，通过 CodeyX 重启 Codex 后完成界面缓存清理。

## 优化与修复

- 拆分原生接口适配，改善模型请求校验、MCP 刷新和会话操作的兼容性。
- 保留官方用量与余额展示，仅清除第三方线路的发送阻塞标记；支持不同账号并发查询用量。
- CodeGraph 仅为工作区已添加的本地项目建立索引，避免误收录聊天目录。
- 减少 CPU 采样、交互心跳和宠物预热带来的后台资源占用。
- 改进 Windows Store 版启动时的进程验证与恢复协调，以及 Crashpad 待上传转储的清理。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- 本版移除按轮次删除消息的功能；会话永久清理无法撤销，不处理项目文件、云端会话或用户另存的导出与备份。
- Windows 实验性流量接管需另备组件并授权管理员权限，常规安装包不包含接管组件；尚不保证系统 DNS 与服务异常退出时无泄漏。
- 出口检测会联系第三方服务，显式允许直连的代理策略可能暴露本机出口；既有手填代理凭据仍可能保存在本地配置和备份中。
- macOS arm64 提供未签名应用包。
