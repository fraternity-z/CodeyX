# CodeyX v1.2.0 · WSL 实验性支持与会话统计

本次更新新增 WSL 实验性支持、New API 连接串快速导入和会话统计状态条，改进配置热更新与用量展示。

## 本次亮点

### WSL 实验性支持

支持 Windows Codex 客户端配合 WSL Linux 后端运行，提供 Linux 版 FastCtx、Hook 和 CodeGraph 接入；WSL 模式仍处于实验阶段，兼容性持续验证中。

### New API 快速导入

粘贴 New API 的连接串即可填入线路地址与密钥，检查后通过正常保存流程启用线路。

### 会话统计状态条

在对话中查看会话轮数、最近一轮活动及缓存命中率，便于了解当前会话的使用情况。

## 优化与修复

- 配置保存后在后台串行应用，展示应用中、失败或需重启状态，并保留尚未保存的新草稿。
- CodeGraph 索引状态按当前会话的工作目录查询，减少不同项目之间的状态混淆。
- 管理面板按核心配置、运行管理和扩展生态分组，改善加载状态展示。
- 用量热力图统一为日历布局，调整月份标签与配色。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- WSL 目前为实验性支持，需要可用的 Linux x64 WSL 环境并启用 Windows 程序互操作；启动失败后可按提示确认切回 Windows 后端。
- New API 连接串包含 API Key，请仅使用可信来源并妥善保管。
- macOS arm64 提供未签名应用包。
