# CodeyX v1.2.1 · MCP 共享与连接恢复

本次更新新增 MCP 共享器和启动动画，改进网络变化后的连接恢复、配置面板加载与 Windows 重启时的设置保存。

## 本次亮点

### MCP 共享器

支持按需共享内置 FastCtx、CodeGraph 和兼容的本地 MCP 服务，并发请求按需分配实例，可释放空闲实例而不打断正在执行的请求。

### 启动动画

新增适配明暗主题与不同窗口尺寸的启动动画，改善 Codex 启动时的等待体验。

## 优化与修复

- 改进网络切换后的上游连接恢复，减少网络变化引起的连接异常。
- 鼠标悬停或聚焦设置按钮时预加载配置面板，减少打开等待。
- Windows 重启 Codex 前请求正常退出，确保设置完成保存。
- 改进会话文件名标识识别与清理范围校验，减少带后缀文件名的误判。
- 减少 MCP 状态扫描，隐藏页面时暂停会话统计调度，降低后台开销。

## 升级须知

- 升级前请结束正在进行的 Codex 任务；下载与安装仍分别确认。
- MCP 共享仅适用于无状态且允许多实例运行的工具服务；依赖客户端回调、资源订阅或持续任务的服务应保持直连。内置工具的共享开关需重启 Codex 生效。
- macOS arm64 提供未签名应用包。
